### 可观测性

6. **ACL 逐规则命中计数**（§1-9）——决策 #68 降 V2 的技术债：govpp v0.13.0 调
   `acl_stats_intf_counters_enable` 会被 VPP 误执行为 `acl_del`（应答错位，可能误删 ACL），
   绑定后 stats 段亦无逐规则计数；需升级 govpp 或自解析 stats segment。
   **尝试未达并已撤回（决策 #339，round118 真机实证；实现随 PR #265 整体回退）**：计数注册确在
   （`/acl/<idx>/matches` 组合计数，口径以 VPP 源码定死），但实测——①「vNIC 作 L3 接口」形态下
   **ACL 确实在拦**（`ACL deny packets` 递增 8→12）而逐规则计数**恒 0**；②启用全局
   `acl_stats_intf_counters_enable`（CRC 两面一致）+ 重绑定后**仍不递增** ⇒ **VPP 26.06 只注册、
   不写该计数**；读视图恒 0 会误导，故整体撤回。**对 #68 的更正**：「调该 API 会被误执行为 acl_del
   （危险）」实测不成立——请求正常执行；报错是 govpp 对**空应答** CRC 碰撞（`0xe8d4e804` 多家共用）
   的识别噪声，ACL 未被误删；结论（不可用）仍成立、原因不同。**后续路线**：待 VPP 版本递增该计数，
   或退用插件 err 族计数（permit/deny 总数粒度）。

   VPP 26.06 的 dns 插件**只在默认表解析上游**（binapi `DNSNameServerAddDel` 无 VRF/fib 字段、CLI

   实测「客户端查询能到 VPP、VPP 永远发不出上游查询」（缓存永久 pending、pcap 无 `.1→上游` 流量），
   配了就是假的。**后续路线（未立项）**：a) 补「默认表寻址」能力后再启；b) 待 VPP dns 支持按表/VRF；
   c) 自研域内 DNS 转发器（新服务，大）。**余**：管理网侧转发（宿主解析器已覆盖，深化另议）。
4. **IPv6 业务面完整性**（§3-4）——地址与静态路由已双栈，但 NAT / ACL 五元组 / 诊断命令
   （ping6/traceroute6）的 v6 覆盖未见证据（待专项核实）；「IPv6 仅管理面 + 静态路由」只能算半双栈。
   **诊断侧已收口（决策 #330）**：`ping ipv6`（VPP v6 平面）与 `traceroute ipv6`（宿主侧 ICMPv6）落地，
   v4/v6 未通即失败同口径，命令树/手册给支持矩阵小表。**余**：NAT44 与 ACL 五元组的 v6 覆盖仍待专项核实（本轮未动）。
5. ~~**QoS 深度**（§3-5）——仅单速 cir/cbs 且只支持 ingress-policy 绑定；无 egress 方向、
   无层级 shaper / 优先级队列 / 丢弃策略。~~
   **出向方向已收口（决策 #331）**：新增 `set/delete interfaces <ifname> egress-policy <name>`，
   数据面复用同一 VPP policer、经 `PolicerOutput`（`policer_output`）与入向 `PolicerInput` 对称，
   同接口入/出两向可并存且各自独立，读视图逐条标注方向。**余**：层级 shaper / 优先级队列 /
   丢弃策略仍属 v3 深化（不在本清单）。
6. **历史时序数据**（§3-7）——`/metrics` 是即时快照、无时序存储；Web 总览 5s 轮询同样没有趋势图
   数据底座，容量规划与事后回溯无从谈起。
7. **`/metrics` 覆盖面**（§3-9）——`internal/metrics` 只采集宿主运行态（/proc 等）；
   VPP / VNF / 容器指标是否进 /metrics 未见证据（待专项核实）。
8. ~~**ping / traceroute 不支持指定 VRF / 源地址 / IPv6**（§3-13）——命令树里 `ping` 仅 VPP 数据面
   IPv4；排障高频细项。~~
   **已收口（决策 #330）**：`ping` 支持 `source`/`count`/`vrf`（既有）并新增 **`ping ipv6`**（VPP v6 平面）；
   `traceroute` 新增 **`traceroute ipv6`**（宿主侧 ICMPv6）；`traceroute` 的 `vrf` 对 v4/v6 都明确拒绝
   并给替代（`ping … vrf`），不静默降级。命令树/手册给「命令 × 平面 × v4/v6 × vrf」支持矩阵小表。
