## 4. 本批教训（入册）

1. **回滚也是「已提交配置变更」**：confirmed 超时回滚只落库、不走 OnCommitted ⇒ 宿主侧重收敛（防火墙/TLS/syslog/日志保留）全都不触发——防火墙场景直接管理面锁死。凡改变 committed 状态的路径都必须走同一通知。
2. **自锁类功能必须测「锁上之后的后半场」**：窗口内拦住流量只是前半场；超时回滚是否真的把访问还回来，才是这类功能的完整验收（P0 就藏在后半场）。
3. **带外恢复要提前盘点且分层**：同会话 established 存活（兜底还原）→ vmrun 免凭据电源控制（复位）→ hypervisor 控制台（人工）；Computer Use 本会话不可用（SDK unavailable），不影响前两级。VM 无串口（vmx 无 serial0）。
4. **nftables 共存语义（真机实证）**：同 hook base chain 相互独立、**drop 全局生效**（高优先 accept 豁免不了别处 drop）；保留 established,related 让既有会话存活；逐规则 counter 真实可读——与 VPP ACL 计数（#339）形成对照。
5. **交接里的环境断言会过时**（autostart:true → 实为 disable）：接手时对环境的关键断言要现场复核，别照抄。
