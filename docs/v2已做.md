### 撤回记录（两例，均按「不留假功能」纪律整体回退）

- **#338 数据面 DNS 代理**（round116）：实现/接线全部落地后真机实证**未达**——VPP 26.06 的 dns 插件
  **只在默认表解析上游**（binapi 无 VRF/fib 字段、CLI 无表参数），而产品 L3 域都是 VRF 且无法在默认表
  配地址；实测「客户端查询能到 VPP、VPP 永远发不出上游查询」（缓存永久 pending、pcap 无出向流量）。
  配了就是假的 → 整体 revert（PR #264），决策行改写为撤回记录。后续路线见 `v2待做.md` 三.3。
- **#339 ACL 逐规则命中计数**（round118）：计数注册确在 stats segment（口径以 VPP 源码定死），但真机实测
  **VPP 26.06 只注册、不写该计数**（启用全局 `acl_stats_intf_counters_enable` + 重绑定后仍恒 0），
  读视图恒 0 会误导 → 整体 revert（PR #265）。**顺带更正决策 #68**：其「govpp 调该 API 会被误执行为
  `acl_del`（危险）」不成立——实测请求 CRC 两面一致、VPP 正常执行；报错是 govpp 对**空应答** CRC 碰撞
  （`0xe8d4e804` 多家共用）的识别噪声，ACL 未被误删；结论（不可用）仍成立、原因不同。后续路线见待做一.6。
