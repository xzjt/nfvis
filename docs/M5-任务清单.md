## 任务清单（M5 主体）

### M5-1 事件总线与 SSE（FR-API-006、FR-OPS-020~022）

- 目标：`internal/events` 事件总线；`GET /events`（SSE）推送 alarm-raised/resolved、VNF 状态变化、镜像导入进度、配置提交；`show alarms` 与 `/alarms` 接同一存储；告警触发源补齐（接口 link 变化、资源阈值、磁盘、配置 confirmed 回滚）。
- 验收：CLI/API 双通道可见；拔插链路/杀 QEMU 后事件实时推送（非轮询）。

### M5-2 Prometheus 指标（FR-SYS-005）

- 目标：`/metrics` 暴露系统（CPU/内存/磁盘/大页）、VPP（接口收发包/错误/drop、BD）、VNF（状态/vCPU）、告警计数；`internal/metrics` 采集器。
- 验收：`curl /metrics` 抓取成功；关键序列在真机有非零值。

### M5-3 数据面抓包（FR-OPS-042）

- 目标：`request vpp trace start|stop|export` + `/vpp/capture`，pcap 导出与下载。
- 验收：真机抓包文件可被 tcpdump/wireshark 打开且含预期流量。

### M5-4 诊断与转储（FR-OPS-040/041）

- 目标：`request system tech-support generate`（版本/配置/日志/审计/状态/core-dump 清单打包，CLI/API 下载）、core dump 收集与滚动清理。
- 验收：归档可下载并含全部小节；core dump 触发（kill -SEGV）后出现在清单。

### M5-5 硬件健康与阈值（FR-SYS-012）

- 目标：`show system hardware`（IPMI/Redfish 降级 lm-sensors、SMART）、`set health thresholds` + `/system/health/thresholds`、越限告警、指标导出。
- 验收：真机读到温度/磁盘 SMART；阈值越限产生告警。

### M5-6 备份/恢复/恢复出厂（FR-OPS-004~007）

- 目标：`request system configuration backup|restore`、`/system/backup`、`/system/restore`、`request system zeroize`（双确认）。
- 验收：备份→zeroize→restore 后配置与账号一致；镜像文件不入备份。

### M5-7 软件升级与电源操作（FR-OPS-001~003、命令树 §1.2）

- 目标：`request system software add|rollback`（deb，失败回退）、`reboot|shutdown`、`ntp sync`；对应 `/system/software`、`/system:reboot|shutdown|zeroize|ntp:sync` 端点。
- 验收：构造新版 deb → 升级 → 版本变更 → 回退成功；重启后配置与业务自动恢复。

### M5-8 TLS/证书与日志保留（FR-SYS-011/013）

- 目标：`set system api tls cert-file|key-file`、自签重签、SSH host key 重生成；`syslog local retention-days|max-size-mb`。
- 验收：换证书后 HTTPS 生效（旧证书指纹变化）；日志超限滚动、审计不丢。

### M5-9 CLI 剩余契约命令接线

- 目标：`show system hardware|core-dumps|tech-support`、`show log system|audit|vnf`、`show users`、`show images` 运行态字段、`monitor vnf`、`clear interfaces statistics`（已接）之外的残留占位提示清零。
- 验收：命令树 §1.1/§1.2 中每条命令可执行或明确标注 V2（不允许“占位提示”继续存在）。

### M5-10 deb 打包与安装/升级路径（骨架 §2 deploy）

- 目标：`deploy/debian` 打包 `nfvisd`/`nfvis-cli`/契约文档/命令树；postinst 完成安装期底座优化校验；systemd 单元与自守护（FR-OPS-013）。
- 验收：纯净 nfvis-vm 上 `dpkg -i` 安装 → `nfvisd` 起来 → CLI 可用；重启后自愈。

### M5-11 端到端验收与基准（规格书 §10）

- 目标：`test/e2e` 覆盖「装完即用」全链路（登录→建交换机→部署 VM/容器→通流→快照→升级→恢复）；性能基准按 §10 指标出报告。
- 验收：e2e 在真机全绿；基准报告归档 `docs/`。

## M5 Done 定义

1. T0-1~T0-7 全部关闭（或明确记为 V2 并记录理由）；
2. M5-1~M5-11 完成；`make check` + `/contract-check` 全绿，契约零漂移；
3. 真机现场演示：事件实时推送、`/metrics` 抓取、抓包导出、tech-support 归档、备份→zeroize→restore、deb 升级与回退；
4. V1 范围内的 FR 需求全部可追溯（实现引用 + 验收记录）。
