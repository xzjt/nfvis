## 2. ⚠️ 真机环境未恢复（接手第一件事）
现状：`nfvis` **卡在 `activating` → systemd 超时被杀 → restart 循环**；`vpp=active` 但**数据面不可用**；
已装 **2.0.0~dev42**（= v2 代码，用于回退验证）。**根因方向**：nfvisd 启动（含恢复收敛）**超过
systemd `TimeoutStartSec`（~90s）**——现场对象比 round127 时重。
```bash
ssh nfvis-vm 'systemctl stop nfvis; systemctl start vpp'     # 先停循环 + 让数据面可用
ssh nfvis-vm 'systemctl show nfvis -p TimeoutStartUSec; journalctl -u nfvis -n 40 --no-pager | tail -40'
```
⚠️ 本轮真机**重启过 3 次**：**自签证书与 SSH host key 会重建**（Web Browser Use 前需重新导入证书：
`certutil -user -addstore Root <pem>`；撤销 `certutil -user -delstore Root nfvis`）；
**Browser 验证必须先绕缓存**（URL 加查询串），否则会把「缓存旧 JS」误判成「修复无效」（round127 §5 的实证）。
⚠️ 1G 池仍被数据面占 1 页（VPP main heap，无法避免）⇒ 声明 2 时 VNF 只能用 1。
