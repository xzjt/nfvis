## 4. 必须知道的技术坑（已写入决策 #39~#48，勿重新踩）

1. **libvirt-qemu 目录穿越**：QEMU 以 uid 64055 运行，VM/镜像目录须 **0755**（`t.TempDir()` 的 0700 会被拒）；
   落盘目录统一 0755（`qemuStorage.EnsureDir`）。
2. **vhost-user link up 条件**：需 **guest 加载 virtio-net 驱动并置 DRIVER_OK**（QEMU 才发 SET_MEM_TABLE，
   VPP `show vhost-user` 的 `Memory regions` 才非零）。**空白盘永不 up** → 真机测试必须用可引导镜像。
3. **vhost-user 队列**：QEMU 侧须 `<driver queues='2'/>`（1 对队列时握手停在 protocol features）。
4. **socket 权限**：VPP 创建的 vhost-user/memif socket 须 **chmod 0777**，否则 QEMU `Failed to connect ... Permission denied`。
5. **domain 确定性 UUID**：`DomainDefineXML` 不带 uuid 时重定义**同名域会报 `already exists with uuid`**；
   `compute.DeterministicUUID(vmName)` 已修复。
6. **VNF vNIC 必须出现在 `virtual-switches[].ports[]`**（`vnf`+`vnf_interface`）才挂接 BD；只配 `interfaces` 会
   「接口建好但非 BD 成员」→ 通流失败。
7. **删除顺序**：BVI 网关是 BD 成员 → **先删 BVI 再删 BD**，且 l2 摘除成员对 **`Invalid sw_if_index(-2)`** 按已摘除
   处理；VPP 侧 vNIC 接口删除**在 BD 删除之后**（BD 删除会摘除成员）。
8. **ping 指定 table-id**：L2 交换机的 BVI 地址位于**专属 VRF** 表（`vr-<交换机名>`，决策 #32），
   `vppctl ping <ip> table-id <TableID("vr-<vs>")>` 才可路由到 guest。
9. **快照**：qcow2 内部快照；**宿主用 `qemu-img dd -O qcow2` 直写会破坏快照 L1/refcount**，之后 revert 报
   `Failed to load snapshot` → 磁盘内容级回滚证明须 **guest 内写入**（随 M4-11 已标注未做）。
10. **go-libvirt**：`DomainOpenConsoleBidirectional` 实测**阻塞挂起** → 串口改读 domain XML 的 **pty 路径**（`SerialPtyPath`→`OpenConsole`）；
    `DomainListAllSnapshots` 的 `NeedResults` 必须传 **1**；外部 `kill -9` QEMU 时 libvirt 报 **`shutoff`+reason=CRASHED(3)**
    （不是 `crashed` 状态）→ 必须 **reason 感知**（`StateReason`/`VMStateFromLibvirtReason`）才能触发 FR-CMP-017 告警。
11. **candidate 自洽**：删除 VM 时必须同时移除引用其 vNIC 的交换机端口条目（否则 FR-CFG-002 校验拒绝），
    通常连交换机一起删。
