## M4-1 libvirt 连接层与 domain XML 组装

**关联**：FR-CMP-010/014/016/018/019、FR-NET-020/021；任务 M4-1。

**交付**：`internal/orchestrator/compute/domain_xml.go`（纯函数 XML 组装）、`conn_libvirt.go`（`_libvirt.go` 薄适配层，覆盖率排除）、`version.go`。

**执行**（nfvis-vm）：

```bash
cd /opt/nfvis/src/nfvis
export https_proxy=http://192.168.155.1:2333 http_proxy=http://192.168.155.1:2333
go test -tags integration -count=1 -v \
  -run "TestLibvirtConnectAndVersion|TestDefineDomainXMLRealLibvirt" \
  ./internal/orchestrator/compute/
```

**结果**：

```
--- PASS: TestLibvirtConnectAndVersion
--- PASS: TestDefineDomainXMLRealLibvirt
ok  	github.com/xzjt/nfvis/internal/orchestrator/compute	0.023s
```

- 连接/版本探测：libvirt 12.0.0（`qemu:///system`），hypervisor QEMU 10.2.1。
- 以 `domain_xml.go` 生成 XML → `DomainDefineXML` 定义 → `DomainGetXMLDesc` 回读，
  **回读结果与配置语义一致**（关键片段）：

```xml
<vcpu placement='static'>2</vcpu>
<cputune><vcpupin vcpu='0' cpuset='6'/><vcpupin vcpu='1' cpuset='7'/></cputune>
<memoryBacking><hugepages><page size='1048576' unit='KiB'/></hugepages><locked/><access mode='shared'/></memoryBacking>
<interface type='vhostuser'>
  <source type='unix' path='/run/nfvis/vhost/it-m4-1-vm-eth0.sock' mode='client'/>
  <model type='virtio'/><driver queues='2'/>
</interface>
<serial type='pty'><target type='isa-serial' port='0'/></serial>
```

- 另在真机用 `virt-xml-validate /tmp/domain.xml domain` 通过，`virsh define` + `virsh dumpxml`
  人工复核一致（含 SR-IOV `hostdev mode='subsystem' type='pci' managed='yes'` 的
  `<address domain='0x0000' bus='0x0b' slot='0x10' function='0x1'/>`，环境无 VF，仅 XML 组装）。
- 删除后 `dumpxml` 失败（断言真正清理）。

**本地门槛**：`internal/orchestrator/compute` 单测覆盖率 **98.9%**（不含 `_libvirt.go`）。

**未验证项（如实标注）**：SR-IOV VF 直通无硬件，仅 XML 组装 + 单测；真机启动 VM 属 M4-3（需大页与磁盘）。
