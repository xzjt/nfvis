## 1. T0 遗留收尾

### T0-1 NAT 拓扑语义决策 + D4 端到端 ✅

**决策 #52**：VPP 26.06 NAT44-EI **支持跨 VRF**，但全实例仅一对 (inside, outside) VRF。
- inside 转发域由规则 `virtual-switch`（须 L3 交换机）派生 `TableID(<vs名>)`；
- outside 转发域由 `action interface` 出接口所属 VRF 派生（接口须为某 Vrf 的 l3-interface 且已配地址）；
- 多规则的 inside / outside 必须各自一致；`action interface` 必填、`action source-pool` 可选；
- **修正校验矛盾**：作废「action 必须且只能指定 source-pool 或 interface 之一」（与决策 #38 及编排实现互相矛盾）。

**关键修复**：原 `NatProvider` 启用插件时 `inside_vrf=0`，而 L3 交换机 inside 接口位于非零表 → NAT 永不命中（M3 D4 失败根因）。
改为把派生 VRF 传给 `nat44_ei_plugin_enable_disable`。

**真机证据**（`docs/evidence/m5/d4-nat-cross-vrf.txt`）：经 `nfvis-cli → nfvisd → VPP` 全产品路径，
内网 tap `10.20.0.2`（table `TableID(nat-l3)`，fib 1）→ 出接口 ens224（`wan` VRF，fib 2），
ping 外网 `192.168.155.2` **0% 丢包**，`show nat44 ei sessions detail` 可见 `i2o 10.20.0.2 fib 1 ↔ o2i 192.168.155.240 fib 2`。
