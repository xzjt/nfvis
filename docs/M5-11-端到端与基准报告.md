## 1. 端到端主链路（「装完即用」）

`TestE2EMainChain` **PASS**（真实 nfvisd + VPP 26.06；全程经 HTTP API，不直连底座）。
覆盖与结果：

| 步骤 | 断言 | 结果 |
|---|---|---|
| 登录 | `POST /login` 取得 token | ✅ |
| 建网（事务） | `interfaces` / L2 交换机 + 端口 + BVI 网关 / L3 交换机 + l3-interface 地址 → `commit` | ✅ |
| 策略配置 | `set system health thresholds …`、`set system syslog local retention-days …` | ✅ |
| 回读校验 | `GET /virtual-switches` 含对象；`GET /system/health/thresholds` 值与提交一致 | ✅ |
| 事件实时推送 | 订阅 `GET /events`（SSE）后提交一次变更 → 6s 内收到 `config-committed`（非轮询，FR-OPS-022） | ✅ |
| 指标 | `GET /metrics`（无鉴权）含 `nfvis_vpp_threads`/`nfvis_alarms_active`/`nfvis_config_virtual_switches` | ✅ |
| 备份/恢复 | `POST /system/backup` → 下载归档（`nfvis-config-backup`）→ `POST /system/restore`（multipart）200 | ✅ |
| 诊断 | `POST /system/tech-support`（202 + 归档名）→ `GET /system/core-dumps` | ✅ |
| 抓包 | `POST /vpp/capture`（ens192）→ `DELETE /vpp/capture`（204）；接口未被 DPDK 接管时接受 400 | ✅ |
| TLS | `GET /system/tls`（未配置返回 `configured:false`） | ✅ |
| 审计 | `GET /audit-logs` 含 `config.commit`（FR-OPS-031） | ✅ |

可重复性：对象名/地址/阈值均带 run 唯一后缀 + 预清理，故同一 nfvisd 上**重复运行不因「值未变化」失败**。

## 2. 性能基准（规格书 §10）

`TestE2EBenchmark`：每项 n=30 次，取 p50/p95。

| 指标 | p50 | p95 | §10 目标 | 判定 |
|---|---|---|---|---|
| `GET /interfaces`（列表） | <1 ms | 1 ms | ≤500 ms | PASS |
| `GET /virtual-machine-functions`（列表） | <1 ms | 1 ms | ≤500 ms | PASS |
| `GET /alarms`（列表） | <1 ms | <1 ms | ≤500 ms | PASS |
| `GET /metrics`（抓取） | 2 ms | 4 ms | ≤500 ms | PASS |
| `CLI show version`（show 类） | <1 ms | 1 ms | ≤1 s | PASS |
| `commit`（1 条变更，含事务+底座下发） | 11 ms | 13 ms | ≤5 s | PASS |

> 说明：以上为**当前实验室环境、空载、对象规模小**的测量值；§10 中吞吐类指标
> （10GbE 线速 ~14 Mpps、vhost-user 单 VM ≥8 Gbps）与容量类指标（≤10 VM/≤20 容器、
> 恢复时间 ≤30s/≤3min）需专用流量发生器与规模压测，**本轮未测**，见 §4。

## 3. 覆盖范围与限制

- 已覆盖：配置事务全链路、事件/指标、备份恢复、诊断归档、抓包、TLS 信息、审计。
- **未纳入 e2e**（各自已有专门真机证据，避免 e2e 具破坏性/环境依赖）：
  `zeroize`（会重置账号，见 `docs/evidence/m5/m56-*`）、`software add/rollback`（会替换安装包，见 `m57-*`）、
  `reboot/shutdown`（会断连，见 `m57-*` 中 systemctl 自守护证据）、TLS 热换证（见 `m58-*`）。
- 硬件极端场景（真实 BMC/温度传感器/磁盘 SMART 越限）受 VM 无 IPMI/传感器限制，见 `m55-*` 的降级验证。
