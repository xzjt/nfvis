§7 R81-2（真机复现、当场修复）：enabled=true 落库后 display set 被自校验拦下
--------------------------------------------------------------------------------
- 用户真机报告：`show configuration | display set` 报 %% 内部错误（上午同命令曾出 42 条语句）。
- 根因：round81 验证中 `request interfaces ens224 enable` 走一次性事务把
  `interfaces[].enabled=true` 显式落库（rev 56）——语句语法只有 disable，enabled=true
  无 set 形态，回放自校验如实拦截（机制按设计工作）。
- 语义判定：Enabled 未显式置 false 即启用（interface_alarm 同口径），enabled=true 与
  缺席**语义相同** → 回放校验两侧精确剥离 `interfaces[].enabled==true`
  （LLDP 等有真语句的 enabled 不受影响），输出与 JunOS 同口径：up 为缺省不落语句。
- 附带修复：display 管道在命令本身已报错时透传原错误——真机实测
  `show configuration / | display set` 的「无效命令」真因曾被「该命令不支持」盖住。
- 修复后真机复验（1.1.35~dev2）：三条命令逐一验证——
  ① show configuration | display set → 42 条语句照常（含 ens224）；
  ② show configuration / | display set → % 无效命令: show configuration /（可用：…）；
  ③ show / | display set → % 该 show 命令形式未支持。可用：…
- 环境终态：nfvis 1.1.35~dev2 active、vpp active、BVI→vnf-a ping 5/5 0%（复跑）。
