**负例**（如实报错、不谎报、不抛 JS 错）：
- `#/network/vrfs/nope` → 页内「以下数据读取失败：/vrfs/{name}/routes（VRF nope 不存在）、/vrfs/{name}（VRF nope 不存在）」；
- `#/compute/containers/nope`、`#/network/acls/nope`、`#/network/bonds/nope`、`#/network/qos/nope`、`#/network/span/nope`
  → 各自「读取失败 / 不存在 / 未找到」文案（qos/span 还写明"该对象没有单独读取的接口"）；
- `#/nope/xyz` → 「页面不存在：#/nope/xyz（已回到总览）」。

**3.2 地址即页面**：深链直达 `…/ui/#/system/interfaces`（整页加载）→ 该页可见、面包屑「系统 › 接口」、首格 `ens192`；
`reload()` 后仍在原页；`#/system/interfaces` → `#/compute/images` → 后退 → 接口页 → 前进 → 镜像页（全部符合）。

**3.3 真执行抽查（低危档，并对照独立事实源）**：`#/ops/actions` 点「生成配置备份」→ 确认框
（**无确认词、按钮为「确定」**，符合低危档）→ 执行后界面「生成配置备份：完成。」、归档表 **7 → 8 行**；
独立事实源：配置库新增审计行 `system.backup 生成配置备份 nfvis-backup-20260924T032414Z.json success`，
且 `/var/lib/nfvis/backup/` 下**真的落了 0600 的归档文件**（3800 字节）。

**3.4 归档下载（super-user 正例，决策 #143 的对照面）**：归档行点「下载」→ 界面「已触发下载：…（3.7 KB）」。

**3.5 只读角色实测**：read-only 账号登入后——**服务端 class 判定是真边界**（点「开始编辑」→「配置（无法进入编辑：
当前 class 无权执行该操作）」；`#/system/users` 整页「…（当前 class 无权执行该操作）」；配置库无变化；
归档下载 → 界面「下载失败：当前 class 无权执行该操作」，与 REST 原文一致）；
**但界面未按角色隐藏写入口**（21 个导航项与各页写按钮全部可见）——设计 §8 该项未实现，见 §5。

**3.6 高危动作真执行**：见 `docs/evidence/v1-closeout-round65-web-console-highrisk-exec.txt`
（建/删用户经闸门真改到底座 + 独立事实源 + 409 原文）。

**3.7 分级确认的桩式自校准**：`make check` 的 `web-console-confirm-selftest` 全绿（含 7 个变异体：
gates/word/timer/reboot/zeroize/dpdk/**rawhttp**——每个拆掉都必须报 ✗），`window.confirm` 归零。

----- 5. 如实登记（本版未修，均已在交接文档/决策 #143 记录）-----
1. `POST /system/kernel:apply|:rollback` **契约声明但服务端从未注册（404）**——控制台如实报错不谎报（待办 §2.3）。
2. §7 要求的「高危审计记意图 + 结果两条」**服务端未实现**（只写一条结果行；round65 实测）。
3. **控制台未按角色隐藏写入口**（设计 §8 / 骨架计划 Step 2 的验收项未实现）——服务端判定是真边界，
   影响面是体验与误导（点下去才被拒），不是越权。修它要跨 ~20 个页面做入口分类 + 浏览器复验，属独立一刀。
4. **`request system …` 的运行期 class 判定比命令树声明松**（执行器取 `request system` 域节点 = O 级 ⇒
   operator 能过 `zeroize`/`reboot`/`software`/`configuration backup` 等**声明为 S** 的命令），
   且 `… backup to <path>` 的目标路径**无校验**（nfvisd 以 root 运行 ⇒ 可把任意文件覆盖成归档 JSON）。
   两条已登记（决策 #143 文末、交接 §2.3），**需单独裁决**。
5. `GET /system/tech-support/{file}` 同为 read-only，而诊断归档内含 `config.json`（同样含口令哈希）——
   同类口径不一致，待裁决。
