§2 实现（d7a1888）
1. **B4/E5**（`internal/api/vm_console.go`）：`consoleTickets.issue` 顺带**清扫已过期条目**——未消费的一次性 ticket
   （如 `-c` 脚本模式申请了却不接管终端）此前**永久驻留**（TTL 只在消费时校验）。采用本仓既有「随访问清扫」idiom
   （与 DHCP 去重窗 `rt.recent` 同法、不新造定时器）。
2. **B5**（`internal/api/cli_compute_oper.go`）：**删除签发期的 `container.shell open … success` 审计**——
   审计只记**真实发生**的会话事件（WS 建立时 open / 断开时 close；失败记 failure，见 `container_shell.go`），
   与 VM 串口 console 路径一致。此前成功会话**两条 open**、脚本模式（不接管终端）也记 success。
3. **E6**（`internal/api/cliexec.go`）：`cliSession` 增 `LastUsed`；`ExecuteAs`（每条命令都走）顺带清扫**空闲超过
   `cliSessIdleTTL`（24h）**的会话态条目——只清**本进程内的显示态**（模式/层级），不触碰引擎侧 candidate/锁
   （后者由既有空闲巡检负责）。执行器增 `now func() time.Time`（测试可注入）。
4. **E7**（`internal/config/engine.go`）：`clearLockStateLocked` 中收敛 `superseded`——删本会话自己的「被接管」记录，
   以及**指向本会话**的条目（被本会话接管过的会话重获尝试机会）。此前映射只增不减。**顺序安全**：接管路径先
   `clear` 后 `superseded[oldKey]=newKey`，清理不会抹掉新记录。
