§0 一句话
---------
内核数据面下 Web 交换机详情页的容器派生端口运行态列不再恒「—」：REST
`GET /virtual-switches/{name}/ports` 逐行补齐 `admin`/`link`/`rx_packets`/`tx_packets`
（与 CLI **同一份** `resolveSwitchPortRuntime` 按展示名合并；取不到即不出现该键），
Web 改为「行内字段优先、statistics 回退」。真机：内核容器场景 Web 显示 `up/up`，
与 CLI / REST / `ip -br link` 四方一致（修复前同位置「—」）。
