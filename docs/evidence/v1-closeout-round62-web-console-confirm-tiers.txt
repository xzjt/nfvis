===== V1 收尾第六十二轮：Web 控制台刀 4a（分级确认组件）=====
日期：2026-09-24；分支 console-ia-confirm；决策 #141 第 4 刀第一段（设计 §7 的落地）

----- 1. 交付 -----
同一个 uiDialog 扩成三档：**低危**（单击确认，不列影响面、无确认词）/**中危**（影响面逐条 + 主按钮标红 +
只读回显 CLI 语句 + Esc/遮罩取消）/**高危**（中危全部 + **确认词输入** + **10 秒倒计时**，两者都满足
才放行；没拿到确认词时"失败关闭"：输入框禁用、按钮永不可点并写明原因）。取消路径清倒计时定时器。
**9 处 window.confirm（覆盖 27 个动作入口）全部升级到对应档位，源码里 `window.confirm(` 归零**。
有意不加确认的写操作（与 CLI 同口径，注释写明理由）：开始编辑、保存到 candidate、确认在途提交
（它在跟自动回滚窗口赛跑）、串口连接、只读诊断。

----- 2. 浏览器操作验收（决策 #141 口径）-----
| 档 | 操作 | 断言 | 结果 |
|---|---|---|---|
| 低危 | 运维页点「生成配置备份」 | 弹框可见、标题=生成配置备份、**无 `#modal-word`**、执行按钮可点、只读回显 `request system configuration backup` | ✓ |
| 低危 | 点「取消」 | 弹框关闭；`#ops-msg` 仍为空（**什么都没执行**） | ✓ |
| 中危 | 点「重启主机」 | **影响面 4 条**、执行按钮 class 含 `danger`、无确认词、只读回显 `request system reboot` | ✓ |
| 中危 | 点「取消」 | 弹框关闭（**主机未被重启**——取消就是不执行） | ✓ |

> **高危档未在浏览器验**（如实登记）：本段只做确认强度，**没有任何已接的高危动作**（zeroize/软件升级/
恢复配置/删用户/证书上传都还在"有意不接"清单里，属刀 4b），故浏览器里点不到高危框。高危的**双闸门**
（确认词 + 倒计时、失败关闭、取消清定时器）由桩式自校准覆盖（293 项断言 + 红-绿：拆 gates/word/timer
各报 ✗）。**刀 4b 接上第一个真高危动作时，必须在浏览器里按 §11.2 补做**（断言：不输词不能执行、
倒计时未完不能执行、输入正确且倒计时走完才可执行；执行后审计有意图与结果、底座状态真的变）。
