----- 1. 交付 -----
配置页由 3 节（系统/接口/资源池）扩到 **13 节**、108 个控件，覆盖**网络域 + 计算域**的配置语句：
虚拟交换机（类型/access VLAN/端口直通开关/网关/网关 vrf·acl/成员端口子表含 trunk·native·acl）、
VRF·路由（描述/三层接口子表/静态路由子表）、ACL（描述/规则子表七字段）、NAT（源地址池/转换规则/静态 1:1/清空）、
QoS（CIR/CBS + 接口节新增入向限速策略）、端口镜像（源两型互斥/分析端口）、聚合（成员/lacp mode·interval/mtu/描述）、
LLDP（启用/通告间隔/按接口覆盖/清空）、虚拟机（13 字段 + 附加数据盘子表 + vNIC 子表）、容器（字段 + 环境变量 + memif vNIC 子表）。
表内增删改 = 对应 set/delete 语义，走既有 candidate → 预校验 → 差异 → 提交/丢弃；本地先判 IP/CIDR、端口与范围、
VLAN、MAC、KEY=VALUE、三选一互斥、标识非空不重名（判不过不写入并标红）。

**未覆盖（如实登记）**：① `interfaces … sriov vf-count`（无硬件环境，沿用"界面暂不提供"口径）；
② `cross-connect <port-a> <port-b>` 的**端口身份**——模型里只有 `cross_connect: bool`，端口号根本不入库
（**模型缺口**，本段未动，表单只给开关）；③ vpp 段与系统段其余字段不在本段清单（维持既有分工，走原始 JSON）。
