§2 决策 #301 真机验证（CLI / REST / Web 三面 + 独立事实源）
REST 面（curl → https://127.0.0.1:443/api/v1）：
- POST /login 返回稳定 token_id（UUID 36 位）；GET /system/api-tokens 清单含
  token_id / user / class / issued_at / expires_at / current（凭据永不回显）
- super 吊销他人会话 204 → 被吊销会话下一请求 401；自吊销（当前会话）204 → 下一请求 401
- 非 super（op301，operator）：清单只见自己；吊销 admin 会话 → 404 统一文案
  「会话不存在或无权操作该会话」（不泄露存在性）；自吊销 204。测试用户建删即用即清（201/200）
CLI 面（nfvis-cli -c）：
- show system api tokens：表格 Token-ID / User / Class / Issued / Expires / Session；
  「当前会话」标记随查看视角正确（CLI 自己的会话标「当前会话」，curl 会话显示 —）
- request system api token revoke <id>：成功文案明确；被吊销会话下一请求 401
审计独立事实源：
- system.api-token.revoke 条目与实际操作一一对应（CLI 与 REST 两侧同源、审计两侧落地）
Web 黑盒（Browser Use，决策 #141 口径）：
- 登录 → 用户与权限页「活动会话 / API Token」卡片：表格 + 本会话标记 + 内存态/TTL/权限说明文案
- 点目标行「吊销」→ 中危确认弹窗（影响面 3 条 + 只读回显对应命令 request system api token revoke <id>）→ 确定
- DOM 后置：目标行消失、计数 6→5、成功提示「已吊销会话 916739a2-…」
- 独立对照：GET /system/api-tokens 无该 ID（余 5 条）+ 审计新增 success 条目
- 截图：docs/images/round89-web-console-api-tokens-card.png
