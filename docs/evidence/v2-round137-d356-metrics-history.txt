## §1 作用效果（独立事实源＝直读 SQLite 库）

默认间隔 60s，首轮采样后：

```
$ nfvis-cli -c "show system metrics history"

序列数:       50
样本数:       50
时间范围:     2026-10-03 10:50:45 ~ 2026-10-03 10:50:45
上次采样:     2026-10-03 10:50:45（正常）
已知指标（35）: nfvis_alarms_active, nfvis_config_container_functions, …
```

同一时刻**直读库**（python3 sqlite3，与产品代码无关的第二事实源）：

```
series: 50   samples: 50
oldest/newest: (1791024645, 1791024645)
meta: [('last_tick_ts', '1791024645'), ('last_error', '')]
```

CLI 的「序列数/样本数/时间范围/上次采样」与直读逐值吻合（50/50、ts 1791024645）；
35 个指标名对应 50 条序列（逐接口 `interface=` 与逐 VNF `kind/name` 标签分列）。

改造前（首轮尚未到时）概览如实报「序列数 0 / 时间范围（无数据）/ 上次采样（无记录：采样器尚未完成一次采集）」

## §2 生命周期（重启/重放/配置漂移）

**① 库跨 nfvisd 重启延续**（`systemctl restart nfvis`）：

```
重启前: (2750, min=1791024645, max=1791025299)
重启后: (2950, min=1791024645, max=1791025343)      ← min 不变（最旧样本留存）、max 前进
```

重装 deb（dev54→dev55→dev56）后同样延续（样本数 2700→…→6250），说明历史库**不随进程生死存亡**。

**② 改配置免重启即生效**：`configure / set system metrics history interval 10 / commit`
（无需重启），直读采样点时间戳的**差分**随之改变：

```
deltas: [60, 61, 10, 10, 10, 10]
```

概览同步显示「采样间隔: 10s（已配置；…）」；改回默认即显示「（默认值；…）」。

**③ 不阻塞启动**：journal 里「历史时序存储已启用」11:01:43.588 →「nfvisd 就绪」11:01:43.609
（相隔 21ms）；采样器 goroutine 在 `systemd.Notify("READY=1")` **之后**才启动（沿用 #348/#351/#354 纪律）。

## §4 对抗性对照

**① 同一物理量、两个事实源**：`/metrics`（无鉴权即时快照）与历史最新点都记 `uptime`，
各自反推的**开机时刻**应一致：

```
live(/metrics): uptime=48443.42  现在=1791025365  → 开机 1790976921.6
hist 最新点:    1791025363 48441.86              → 开机 1790976921.1
两源差: 0.4 秒
```

**② 存储不可用如实报**（造现场：用**目录**占住库路径，可逆）：

```
journal: WARN 历史时序存储打开失败，历史采样已禁用
         path=/var/lib/nfvis/metrics.db err=读取历史库 schema 版本: unable to open database file (14)
CLI:     历史时序存储: 不可用（历史时序库打开失败：读取历史库 schema 版本: unable to open database file (14)）
         提示: 存储不可用时不会编造历史数据；请确认 nfvisd 以 -metrics-db <路径> 启动且该库可打开。
```

还原后立刻恢复（样本 3400）。**注意与「窗口内无数据」的区别**：前者是「读不出来」，后者是「确实没有」，
读视图与 CLI 文案分别表述。

**③ 鉴权口径**：无 token `GET /metrics/history` → **401**；无 token `GET /metrics` → **200**
（`/metrics` 的无鉴权契约**未变**，抓取方不受影响）。

**④ 参数与边界**：`last=xx` → **400** + 可照做文案（`无效时长 "xx"（须为正整数 + 单位 s|m|h|d…）`）；
`limit=999999` → 200（夹取到 10000，不报错，越限置 `truncated`）。

**⑤ CLI 抗误用**（rc=1，均给可照做提示）：

```
%% 无效命令: show system metrics history last 1h（可用：history [name <metric> [last <duration>] [step <duration>]]；last/step 须跟在 name <metric> 之后）
%% 无效命令: show system metrics foo（可用：history [name <metric> [last …] [step …]]）
%% 无效命令: show system metrics history name a b（可用：name <metric> [last …] [step …]）
未知指标 nfvis_no_such_metric：存储内尚无该指标。用 show system metrics history 概览可列出已知指标名。
```

## §7 本轮修掉的问题（真机/复核实测暴露，均已回归）

1. **概览「（默认）」注记恒真**——原实现把生效值同时当左右两侧比较（`historyIntervalDefault() == interval`），
   现场 `interval=10` 仍显示「（默认）」。改为与**模型默认值**比较，并新增单测
   `TestMetricsHistoryIntervalNote`（默认值→「（默认值」、改过→「（已配置」）。
2. **`truncated` 用「点数 == limit」猜**——会把「正好这么多点」误报成被裁剪。
   改为存储侧**真值**（`QueryResult.Truncated`：原始点数**超过** limit 才置位），
   新增 `TestQueryTruncatedIsTruthful`（恰好等于 limit **不**置位）。
3. **查询失败被答成「窗口内无数据」**——库可打开但该次查询出错时，原实现保持 `available=true` 且空 `series`，
   与「确实没有」不可区分。改为 `available=false` + `reason="历史时序查询失败：…"`（读不出来 ≠ 没有）。
4. **删空 `system.metrics.history` 留空壳**——`delete system metrics history interval|retention-days` 删光两个叶子后
   配置里留 `{"history":{}}`，`show configuration | display set` 反推为空语句、**回放自校验报内部错误**
   （与 round84 空 `nat` 同族）。`pruneEmptySingleton` 增一层剪枝（先剪内层 `history` 再判外层 `metrics`），
   新增回归 `TestMetricsHistoryConfigRoundTripAndPrune` / `TestMetricsHistoryConfigZeroMeansDefault`。
5. **Web 坐标轴浮点原始串**——直接 `String(v)` 会显示 `0.17999450927800728`（读不出、占满轴）。
   压缩到 4 位有效数字（`_bytes` 仍走 `bytes()` 人读化）。Browser 复核实测：0.18 / 0.1799。
6. **`limit` 无上界** → 夹取 `MaxQueryLimit=10000`（夹取而非报错；越限置 `truncated`）。
7. **架构守护连带**：`internal/schema` 的 `K("metrics", "历史时序存储（决策 #356）")` 把决策号写进了
   **操作者可见**的节点描述，被 `archtest/user_text_test.go` 正确拦下 → 描述串去掉决策号（注释里保留）。

## §9 未在本轮（如实登记）

- **不新增告警码**：采样停滞只在读视图以 `stale` + `last_tick_ts` 如实呈现；「采样停滞告警」需与告警对账
  口径一起设计，登记为后续。
- **不含 rate**：历史点是采样瞬间值，计数器单调递增，速率由读侧差分（读视图与手册均明说，不伪造）。
- **不进配置备份/恢复语义**：`metrics.db` 是运行数据，备份的是配置。
- **`request system storage format-data`** 会清数据分区，历史随之清空——既有语义，未额外扩展。
