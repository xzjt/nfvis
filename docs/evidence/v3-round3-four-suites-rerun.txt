§4 顺带补验 #428（远程 syslog 报文头主机名随配置动态取，handoff §3.3①）
--------------------------------------------------------------------------------
  手法：VM 上起 UDP 监听（python3 绑 0.0.0.0:5514）→ `set system syslog host 127.0.0.1 port 5514`
        → 用健康阈值告警当触发器（`set system health thresholds disk-used-percent 1` 触发
        HARDWARE_THRESHOLD，告警变更经 FR-OPS-022 转发远程 syslog）→ 再 `set system hostname
        nfvis-syslog-x` 提交 → 复看后续报文的 RFC5424 头 HOSTNAME 字段。
  结果（原样）：
    08:48:57 … nfvis-lab    nfvisd 60730 alarm - [HARDWARE_THRESHOLD] … state=active
    08:49:39 … nfvis-syslog-x nfvisd 60730 log - 远程 syslog 转发已配置 …
    08:49:39 … nfvis-syslog-x nfvisd 60730 log - 系统基线已应用到宿主 item=hostnamectl set-hostname nfvis-syslog-x
  —— 改主机名（未重启 nfvisd，PID 恒为 60730）后新报文的 HOSTNAME 即变 ⇒ #428 成立。
  收尾：主机名还原 nfvis-lab、删 syslog host 配置、阈值还原 85、停监听；
        HARDWARE_THRESHOLD 告警在下一巡检周期自动消解（只剩既有的 HUGEPAGE_POOL_ORPHAN）。
