- REST `GET /alarms`：`[{"code":"VNF_PORT_DOWN","time_synced":true}]` ✓ 字段真的发得出来
- CLI `show alarms`：表格行正常渲染（时钟已同步故无 `[时钟未同步]` 标记——标记只在 false 时出现）
- 如实登记：**未同步态（false + 标记）本轮未在真机走**（需停 NTP 再触发），该路径由单测以探针注入覆盖；
  真机补做建议：`timedatectl set-ntp false` → 触发任一告警 → 核字段与标记 → 恢复
