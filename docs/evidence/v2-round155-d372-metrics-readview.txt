§2 实现（ff4c1e3）
1. **A2**（`cmd/nfvisd/metrics_history.go`）：采样循环睡眠切成 ≤`metricsSleepSlice`(1s) 片段、**每片重读生效间隔**并按累计时长判断 tick——
   间隔改小在下一片内生效并重新计时（不再等整段旧睡眠结束）。
2. **A5**（`internal/api/metrics_history.go`）：`store.enabled` 先置 true（语义＝存储已启用），`ReopenIfReplaced`/`Stats` 失败时
   **不翻 false**，如实写 `store.error` + `reason`（渲染给出「读取失败」而非「未启用」）。
3. **A6**（同上，收敛口径）：不新增不可达字段；整体读失败经 `reason`/`store.error` 呈现（渲染的不可用分支已打印 reason）。
4. **A7**（`parseHistoryDuration`，CLI 与 REST 同源）：`historyMaxDuration = 3650d` 上界 + 溢出防护（`d <= 0 || d > 上界` 即报错）。
5. **A8**（`internal/metricshist/store.go`）：抽出纯函数 `planBoundedLoad` 计算有界载入计划——`step>0` 把窗口收窄到
   「最新 limit+1 个桶」（**锚点**：给了 until 用它；哨兵=未给时以最新样本为锚；无样本则不收窄），`step<=0` 走 SQL `DESC LIMIT limit+1` 再反转；
   `Truncated` 为真值。
