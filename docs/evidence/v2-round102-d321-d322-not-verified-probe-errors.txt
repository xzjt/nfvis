§1 ❌ #322（恢复收敛顺序）未验成 —— 探针错误
- 我的造现场两步**都返回 400**：`POST /virtual-switches {"type":"l3","l3_interfaces":[{"interface":"ens192","addresses":["198.51.100.1/24"]}]}`
  与随后的建 VNF —— 即**场景根本没建起来**（L3 交换机的 REST 载荷形状我写错了，字段名/结构与契约不符）。
- 因此后续「No such FIB/VRF 出现 0 次」「vppctl 表存在」「无未收敛告警」**都不构成证据**（没有对象可收敛）。
- 正确的复验口径（下一步照此做）：先用 `?`/契约确认 L3 交换机与 l3-interface 的**正确 REST/CLI 形状**
  （CLI 路径是 `set virtual-switches <n> l3-interface <if> address <cidr>`），再建 VNF 并把 vNIC 声明到该交换机，
  然后 `request vpp restart` + `systemctl restart nfvis`，断言**首次收敛**即无 `No such FIB / VRF`，
  并以 `vppctl show interface address`（该 vNIC 在目标表内）与 `vppctl show ip table`（表存在）作为独立事实源。
