§1 R100-1 根因（修法的事实依据）
`AGENTS.md` 口径是「`-c` 脚本模式任一行失败即停止」，而脚本模式的实际判据只有
`strings.Contains(out, "%%")` —— **只认双百分号**。真机上 `show system <未知子命令>` 的错误文案是
`fmt.Sprintf("%% 无效命令: show system %s（可用：…）\n", …)`，**`%%` 在格式串里被折叠成单个 `%`**，
于是后续语句照跑（退出码非 0 只因最后一行自己报了 `%%`）。
更深一层：失败判据**存在两套且已漂移**（脚本模式的 `Contains("%%")` vs 向导 `stepFailed` 的
「行首单/双 `%` 或『校验失败』」——后者才是文档口径）。
⇒ 修法：判据收敛到 **`cli.OutputFailed` 单源**（向导与脚本共用一个实现，不新造第二套），
`runScriptLinesTo` 作为 `-c`/`-f`/`-f -` 的唯一执行落点，**首个失败行即停止**并如实报
「第几行 + 原文 + 原因 + 其余 N 行未执行」；`res.Warning`（#190「值未变化」是提示）明确不判失败。
