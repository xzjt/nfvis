----- 1. 交付 -----
- 两条新路由：#/config/history（/configuration/history）、#/config/sessions（/system/configuration/sessions）；
  配置页加「提交历史」「编辑锁会话」两个入口。
- 历史页：Rev/时间/用户（空值如实显示「（未记录）」）/注释/当前标记；**回滚两段式**（取历史快照为 candidate，
  不直接生效 → 引导到配置页走 差异→预校验→提交/丢弃）；确认框按**中危**写（影响面逐条 + 主按钮标红 +
  只读回显 rollback <n> + Esc/遮罩取消）。
- **实测坑（子代理查证）**：`rollback/{n}` 的 n 是**相对最新 committed 的偏移**（n=1 = 最新版的前一版），
  不是 Rev 号——页面按「最新 Rev − 该行 Rev」换算；当前生效行不给回滚入口。
- 409（本会话未持 candidate）时先取锁再重试一次；锁在别人手里则报出持有者，**不覆盖别人的候选**。
- 契约边界如实处理：`/configuration/diff` 只有「候选 ⇄ 生效配置」，**没有按 rev 比对**的 REST 路径
  （CLI 的 compare rollback 挂在管道上），故「看差异」做成引导对话框——**不发明端点、不发请求**，
  并说明方向相反（CLI 快照→committed；配置页 committed→候选，改动内容是同一份）。
- 会话页只读（holder/取锁时间/最后活动/是否有未提交改动/在途 confirmed）；释放走配置页「丢弃并结束编辑」
  （与 CLI Teardown 对齐，不提供强制夺锁）。
- 覆盖：已接 68→**71** / 未接 30→**28**（history、rollback/{n}、sessions 三条移出未接，理由按实情改写）。

----- 2. 浏览器操作验收（决策 #141 口径）-----
环境：明文开发态实例（/root/src-ia 构建 + 生产库副本 0.0.0.0:8443；生产库全程未变）。

| 操作 | 断言 | 结果 |
|---|---|---|
| 打开 #/config/history | 面包屑「配置 › 提交历史」；rev 55 行标「当前生效（当前生效，无需回滚）」且**无回滚按钮**；rev 54/53 有「看差异 / 回滚到这一版」；用户列如实显示「（未记录）」 | ✓ |
| 点 rev 54 行「回滚到这一版」 | 中危确认框：标题写明「第 1 版（revision 54，提交于 …）」、影响面 6 条（以该版为底稿建候选 / 运行配置此刻不受影响 / 不提交不生效 / 提交前用差异与预校验 / 取候选占编辑锁 / 锁被别人持有时会失败并说明是谁）、**主按钮标红**、有取消、只读回显 `rollback 1` | ✓ |
| 点「取为候选（不提交）」 | 跳到 #/config，提示「已把第 1 版取为候选（未提交）…」，**差异已显示真实内容**：`[edit interfaces] + bvi0 ;`（rev 54→55 的真实改动） | ✓ |
| 打开 #/config/sessions | 显示本会话持锁：`admin@api / api / 取锁时间 / 最后活动 / 有（有未提交改动）`——与独立事实源（CLI `show system configuration sessions`）同源 | ✓ |
| 点「丢弃并结束编辑」 | 编辑态退出；会话页变「（当前没有会话持有编辑锁）」——**锁已释放** | ✓ |

> **没有提交**：全流程只到"取为候选 + 丢弃"，**运行配置与 VPP 未被触碰**（这既是安全做法，也正好验证了
> "不提交就不生效"这条语义）。
> **未验如实登记**：① 「看差异」是引导对话框（REST 无按 rev 比对的路径），未在浏览器里验到"显示历史差异"；
> ② 历史页的**提交**（第二段的最终生效）未做（会改运行配置，本机是生产拓扑）；③ 按角色隐藏写入口未做（刀 4）。
