§2 实现（b7bbc85）
1. **E9**（`cmd/nfvis-cli/main.go`）：`resolveScript` 增 `cmdlineSet/fileSet`（`flag.Visit` 判定标志是否**显式出现**）——
   `-c ''`/`-f ''`（给了空值）与空文件一样报错；两标志都没给才进交互模式；互斥判定改按「标志给出」而非「值非空」。
2. **B9**（`provider.go` + `docker_client_docker.go` + `container.go` + `cli_compute_oper.go`）：`ExecResult` 增 `ExitCodeNote`；
   退出码读取失败 ⇒ **保留已捕获 stdout/stderr**、`HasExitCode=false`、note 说明；REST 回 `exit_code_note`（无 `exit_code`）、CLI 打印 `⚠` 行。
3. **E12**（`cliexec.go`）：`execSetDelete` 前置守卫——`delete system login user <name>` 且 name==调用者 ⇒ `%% 不能删除当前登录用户`（与 REST 同文案）。
4. **D3**（`hugepages.go`）：同 dev:inode 多映射的页数/尺寸取**最大视图**（页数优先，平局按 `pageSizeRank` 1G>2M 确定性 tie-break）——与 /proc 扫描顺序无关。

§4 真机验证（dev87）
- **E9**：`nfvis-cli -c ''` ⇒ `% -c 的脚本为空：没有任何命令可执行（要进交互模式请去掉 -c）`、**rc=1**（不经管道量退出码）；
  `-f ''` 同款；`-c '' -f x` ⇒ 互斥文案；对照 `-c "show version"` 照常输出（dev87）。
- **E12**：CLI `delete system login user admin`（以 admin 身份）⇒ `%% 不能删除当前登录用户`；
  REST 对照 `DELETE /system/login-users/admin` ⇒ **409 + 同文案**（两侧同判据）。
- **D3**：`show system hugepages` 连续三次取样**逐字一致**（1G：声明 2/实际 2/在用 2/持有 2/数据面 1；2M：持有 530/数据面 530）；
  独立事实源 `/proc`：`vpp_main` 有 **2** 个 1G 页映射、`qemu-system-x86` 有 **1** 个，且两者**共享 inode 195763**（vhost-user 把 guest RAM 映射进 VPP）——
  视图 held=2（两个不同 inode，共享页只计一次）、dp=1（仅 VPP 主堆为独占）与事实一致。
  **如实边界**：本机两个映射的视图长度相同（各 1 页），「视图长度不同」的漂移场景由单测（两种扫描顺序）确定性覆盖；
  真机侧以「三次取样一致 + 与 /proc 事实一致」佐证。
- **B9**：无真机注入通道（需 Docker inspect 失败）——**如实登记：由单测覆盖**（API 层 + CLI 渲染各一条）。
