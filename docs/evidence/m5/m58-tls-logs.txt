$ cat /etc/systemd/journald.conf.d/nfvis-retention.conf

### 5) SSH host key 重生成（FR-SYS-011）

### 说明
- 配置声明式入口：`set system api tls cert-file|key-file <path>`、`set system api tls self-signed regenerate`；
  命令式入口：`PUT /system/tls`（PEM 安装，校验配对）、`POST /system/tls:regenerate`；CLI 同上。
- 证书临近过期（<30 天）由 60s 巡检产生 CERT_EXPIRING(warning) 告警（同 /alarms、/events）。
- 验收后已移除测试证书与 journald drop-in（恢复原状态）；SSH host key 为重生成后的有效新键。
