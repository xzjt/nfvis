## 0. 前置检查（全绿再开始，约 5 分钟）

```bash
ssh root@nfvis-vm

# 0.1 若虚机重启过：重绑 DPDK（ens192/ens224 会回到 vmxnet3）——见 docs/M3-进度交接.md
modprobe vfio-pci; echo Y > /sys/module/vfio/parameters/enable_unsafe_noiommu_mode
for d in 0000:0b:00.0 0000:13:00.0; do
  echo $d > /sys/bus/pci/drivers/vmxnet3/unbind 2>/dev/null || true
  echo vfio-pci > /sys/bus/pci/devices/$d/driver_override
  echo $d > /sys/bus/pci/drivers/vfio-pci/bind
done

# 0.2 起 VPP（注意：provision 有意设为不自启，避免抢占网卡）
systemctl start vpp; sleep 8
vppctl show interface                      # 期望：ens192、ens224 均 up（admin/link）
vppctl show plugins | grep -E 'tap|vhost_user|memif|acl|nat|span|policer'   # 记录可用插件

# 0.3 起 nfvisd（开发态明文 HTTP；首次启动打印一次性 admin 口令，务必记下）
cd /opt/nfvis/src/nfvis
pkill -x nfvisd 2>/dev/null
go run ./cmd/nfvisd -listen :8443 -db /tmp/nfvis-demo.db &   # 记下打印的 admin 口令
export NFVIS_PASSWORD='<上一步打印的口令>'

# 0.4 CLI 连通性
go run ./cmd/nfvis-cli -c "show version"
```

**通过判据**：`show version` 返回 nfvis/VPP/DPDK 版本；VPP 两个业务口 up。

## 1. 演示对象与清理

演示统一用 `demo-` 前缀（集成测试用 `it-`，互不干扰）。开始前与结束后各清理一次：

```bash
go run ./cmd/nfvis-cli -c "configure
delete virtual-switches demo-l2
delete virtual-switches demo-l3
delete acls demo-acl
delete nat source-pool demo-pool
delete port-mirroring demo-span
delete qos policies demo-limit
commit"
```

## 2. D1｜L2 转发与 MAC 学习（FR-NET-010/011/016）

```bash
go run ./cmd/nfvis-cli -c "configure
set interfaces ens224 description demo-l2-port
set virtual-switches demo-l2 type l2
set virtual-switches demo-l2 gateway ip 192.168.155.201/24
set virtual-switches demo-l2 ports 1 interface ens224
commit"

# 从管理口 ping BVI（经 VMnet8 → ens224 → BD → BVI）
ping -c 3 192.168.155.201

# 证据
go run ./cmd/nfvis-cli -c "show virtual-switches demo-l2 detail"
go run ./cmd/nfvis-cli -c "show virtual-switches demo-l2 mac-table"
go run ./cmd/nfvis-cli -c "show interfaces ens224"
vppctl show bridge-domain
```

**预期**：ping 通；`mac-table` 学到网关与宿主 MAC；`show interfaces ens224` 收发包计数非零。

**"两端口桥接"完整版（可选，需要 tap 插件）**：若 `show plugins` 有 `tap`，可加一条 tap 进同一 BD 做真正的两端口转发：

```bash
vppctl create tap id 0 host-if-name vpptap0
ip addr add 10.10.0.2/24 dev vpptap0; ip link set vpptap0 up
go run ./cmd/nfvis-cli -c "configure
set virtual-switches demo-l2 ports 2 interface tap0
commit"
ping -c 3 -I vpptap0 192.168.155.2     # 经 BD: tap0 ↔ ens224 转发
```
无 tap 插件时：如实记录「单端口 + BVI 可达 + MAC 学习已验证，两端口桥接留待 M4 用 vhost-user VM 演示」。

## 3. D2｜L3 / VRF / 静态路由 / BVI 跨网段（FR-NET-013/014）

```bash
go run ./cmd/nfvis-cli -c "configure
set virtual-switches demo-l3 type l3
set virtual-switches demo-l3 l3-interface ens192 ip address 192.168.155.200/24
set virtual-switches demo-l3 static-routes 0.0.0.0/0 next-hop 192.168.155.2
set virtual-switches demo-l2 gateway ip 10.10.0.1/24
commit"

# 跨网段证明：管理口加一条经 VPP 的静态路由，访问 BVI 所在的 10.10.0.0/24
ip route add 10.10.0.0/24 via 192.168.155.200 dev ens160
ping -c 3 10.10.0.1          # 期望通：管理网段 → VPP VRF → BVI(10.10.0.1)

# 证据
go run ./cmd/nfvis-cli -c "show vrfs"
go run ./cmd/nfvis-cli -c "show vrfs demo-l3 detail"
go run ./cmd/nfvis-cli -c "show vrfs demo-l3 routes"
vppctl show ip fib table <demo-l3 的 table-id>
```
**预期**：ping 通（同网段 BVI 与跨网段 BVI 都通）；`show vrfs demo-l3 routes` 含默认路由。
结束记得 `ip route del 10.10.0.0/24`。

## 4. D3｜ACL deny 生效与命中计数（§4.3）

```bash
go run ./cmd/nfvis-cli -c "configure
set acls demo-acl rule 10 source 192.168.155.129/32 destination any protocol icmp action deny
set virtual-switches demo-l2 gateway acl-in demo-acl
commit"

ping -c 3 192.168.155.201    # 期望：100% 丢包
go run ./cmd/nfvis-cli -c "show acls"
go run ./cmd/nfvis-cli -c "show acls demo-acl detail"   # 期望：命中计数增长

# 放行（删除 deny 规则后重新 commit）
go run ./cmd/nfvis-cli -c "configure
delete acls demo-acl rule 10
commit"
ping -c 3 192.168.155.201    # 期望：恢复通
```
**注意**：若 `source` 应填的是管理口真实地址，用 `ip -4 addr show ens160` 确认为准。命中计数在 VPP 26.06 上可能因 govpp stats 解码限制显示不足（见附录 A #34），此时以"ping 被拒 + VPP 侧 ACL 计数"作为替代证据并在记录中注明。

## 5. D4｜NAT 源转换（§4.3）

```bash
go run ./cmd/nfvis-cli -c "configure
set nat source-pool demo-pool address-range 192.168.155.220 to 192.168.155.225
set nat rules 10 match source 10.10.0.0/24 virtual-switch demo-l2 action source-pool demo-pool
commit"

# 首选（无需 tap）：让 VPP 自己从内网侧发起 ping（源地址为 BVI 10.10.0.1）
vppctl ping 192.168.155.2 source 10.10.0.1 repeat 3
# 备选：tap 侧发起（D1 已建 tap 时）
ping -c 3 -I vpptap0 192.168.155.2

# 证据
go run ./cmd/nfvis-cli -c "show nat"
go run ./cmd/nfvis-cli -c "show nat sessions"
```
**预期**：ping 通，且 `show nat sessions` 出现 10.10.0.0/24 → 192.168.155.22x 的会话。
若引擎要求 inside 侧写 L3 交换机名而非 L2 名，以 `?` 候选与 `show nat` 实际输出为准，并把差异记入记录（M3 真机记录见 `docs/M3-进度交接.md`）。

## 6. D5｜SPAN 端口镜像（§4.3）

有 tap 插件时（推荐，能真看到镜像帧）：

```bash
vppctl create tap id 1 host-if-name vppspan0
ip link set vppspan0 up
go run ./cmd/nfvis-cli -c "configure
set port-mirroring demo-span source interface ens224 direction both
set port-mirroring demo-span analyzer interface tap1
commit"

tcpdump -i vppspan0 -c 10 -nn &      # 期望：看到 VMnet8 上的镜像帧（广播/ARP 等）
ping -c 5 192.168.155.2              # 制造流量
```
无 tap 时的降级证据：`show port-mirroring` 配置生效 + 分析口的 VPP 计数增长，并在记录中注明"未做抓包实证"。

## 7. D6｜端口限速（QoS policer，§4.3）

```bash
go run ./cmd/nfvis-cli -c "configure
set qos policies demo-limit cir 1000000 cbs 100000
commit"
# 绑定（以 ? 确认节点；契约见 CLI 文档 §2.5）
go run ./cmd/nfvis-cli -c "configure
set interfaces ens192 ingress-policy demo-limit
commit"

ping -c 20 192.168.155.2              # 期望：出现丢包（1Mbps 限速下 ICMP 触发限速）
go run ./cmd/nfvis-cli -c "show qos policies"
vppctl show policer
```
**预期**：限速前 0 丢包、限速后出现丢包；policer 计数增长。

## 8. D7｜LLDP（FR-NET-018）——本环境受限，如实记录

```bash
go run ./cmd/nfvis-cli -c "configure
set protocols lldp enable true
set protocols lldp interface ens224 enable true
commit"
go run ./cmd/nfvis-cli -c "show lldp neighbors"
vppctl show lldp neighbors
```
**已知**：vmxnet3/DPDK 环境下 VPP LLDP 自身报 `internal error`，且 VMnet8 无 LLDP 对端（附录 A #34、M3-10 记录 §6）。
**记录方式**：结论写「配置下发与查询通路已验证；邻居上报受环境限制未验证，待具备 LLDP 对端的环境回归」——**不得写成通过**。

## 9. D8｜VPP 重启后配置自动重放（DoD 4，FR-OPS-011）

```bash

vppctl show bridge-domain                   # 期望：demo-l2 的 BD 已自动重建
```

**预期**：无需人工重配即恢复；`show vpp` 状态为 running、无 pending-restart。

## 11. 故障排查

| 现象 | 处理 |
|---|---|
| `vppctl` 无 ens192/ens224 | 重绑 DPDK（§0.1）；确认 startup.conf 中 `dev` 已列该 PCI |
| nfvisd 启动报版本不符 | 必须 VPP 26.06（FR-SYS-007 版本锁定）；`vppctl show version` 核对 |
| CLI 401/403 | 口令取首次启动打印值；class 权限见决策 #25 |
| 与集成测试互相干扰 | `make integration` 前 `pkill -x nfvisd`；演示前 `pkill -x nfvisd` 后重启 |
| commit 报资源被引用 | 先删引用方（端口/规则）再删被引用对象（409 语义） |
| ping 不通但配置都在 | 查 `vppctl show interface` 是否 up、`show ip fib` 是否有路由；检查 ACL/policer 是否误挂 |
