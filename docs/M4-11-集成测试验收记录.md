## 5. 主链路暴露并修复的缺陷（附录 A #48）

1. **VNF 端口必须出现在 `virtual-switches[].ports[]`**：vNIC 仅在 `ports` 中以 `vnf`+`vnf_interface` 声明时才挂接 BD；
   只配 `interfaces` 而不配端口 → vhost-user 接口建好但**不是 BD 成员**，BVI 无法转发到 guest（ping 0 received）。
   （校验层已能在引用缺失 VNF 时报错，但「vNIC 未入任何端口」是合法配置，故需测试覆盖正确用法。）
2. **domain 重定义报 `already exists with uuid`**：`DomainDefineXML` 不带 uuid 时重定义同名域被 libvirt 拒绝
   （改 vCPU 步骤暴露）。修复：domain XML 写入**由 VM 名派生的确定性 UUIDv5**（`DeterministicUUID`），
   重定义/恢复收敛身份稳定。
3. **删除顺序两处错误**（VPP 报 `-120`/`-2`）：
   - BVI 网关是 BD 成员，须**先删 BVI 再删 BD**；且 l2 摘除成员时对**已失效 sw_if_index（-2）**按已摘除处理；
   - VPP 侧 vNIC 接口（vhost-user/memif）的删除须**在 bridge-domain 删除之后**（BD 删除会摘除成员），
     调整 applier 删除段顺序。
